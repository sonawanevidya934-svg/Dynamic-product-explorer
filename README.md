# Dynamic Product Explorer

A responsive web application that allows users to explore products dynamically using JavaScript and a REST API.

## Features

- Dynamic product listing
- Product search and filtering
- Responsive user interface
- REST API integration
- JavaScript DOM manipulation
- Mobile-friendly design

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- REST API

## Project Structure

- `index.html` – Main webpage
- `style.css` – Styling and responsive design
- `app.js` – DOM and application logic
- `api.js` – API integration

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in a browser.

## Architecture

User Interface → JavaScript Application → REST API → Product Data

## Project Goal

The goal of this project is to demonstrate responsive design, dynamic JavaScript functionality, API integration, and modern web development practices.
